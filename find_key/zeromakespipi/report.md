# Учебное пособие - ZeroMakesPiPi

## Analyst: Velana

## Tools Used:  IDA Pro (статический анализ), Linux (среда Wine)

## Цель задания

1. Найти правильный серийный номер

## Решение

1. Открыв исполняемый файл в IDA Pro, я начала исследование с проверки строк (вкладка Strings). Найдя строку "Well Done!", я решила идти от обратного и перешла по перекрестной ссылке (XREF) из адреса .rdata:00402620, где хранится этот текст. Так я попала в функцию обработки события sub_4013B0 (обработчик нажатия кнопки в графическом окне).
2. Переключившись в окно декомпилятора (Pseudocode), я увидела, что текстовые данные, введенные пользователем, передаются в функцию atof, которая преобразует их в вещественное число с плавающей точкой повышенной точности (double) и записывает в переменную str_to_double.
3. Далее программа выполняет строгое сравнение введенного пользователем числа (str_to_double) с эталонным значением, которое возвращает математическая функция get_pi_leibniz()
4. Функция get_pi_leibniz высчитывает число \(\pi \) методом знакочередующегося ряда Лейбница за 20 000 итераций. Декомпилированный код этой функции выглядит следующим образом:

    ```C
    // Фрагмент функции get_pi_leibniz
      pi_sum = 0.0;
      counter = 2;
      denominator = 1;
      iterations = 20000;
      do
      {
        base = -1;
        exp_copy = counter;
        if ( counter < 0 )
          exp_copy = -counter;
        pow_result = 1;
        while ( 1 )
        {
          if ( (exp_copy & 1) != 0 )
            pow_result *= base;
          exp_copy >>= 1;
          if ( !exp_copy )
            break;
          base *= base;
        }
        if ( counter >= 0 )
          sign = pow_result;
        else
          sign = 1 / pow_result;
        ++counter;
        --iterations;
        current_term = (double)sign / (double)denominator;
        denominator += 2;
        pi_sum = pi_sum + current_term;
      }
      while ( iterations );
      return pi_sum * 4.0;

    ```

5. Математический расчет данного алгоритма за 20 000 циклов дает точное значение 3.1415426535898248.
6. Если введенное пользователем число байт-в-байт совпадает с вычисленным значением, вызывается метод CWnd::SetDlgItemTextA, который выводит в текстовое поле сообщение об успешном прохождении проверки: "Well Done!".
7. При вводе серийного номера 3.1415426535898248 программа успешно вывела "Well Done!".
