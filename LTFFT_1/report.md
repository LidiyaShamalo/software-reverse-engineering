## Часть 1: Поиск действительного пароля

1. Первоначальный анализ: Открыв исполняемый файл в IDA Pro и перейдя в окно Subviews -> Strings, сначала я проверила наличие готовой строки пароля. Не найдя её, решила отталкиваться от обратного и перейти по перекрестной ссылке строки _main+8D от адреса .rdata:00403118, где хранится текст "Bad... you should work harder.\n\n". Так я попала в ветку условного перехода в функции _main. Чуть выше по коду там сравниваются две строки. Определенно одна из них ввод пользователя, а другая наш наш верный пароль. Выяснилось, что целевой пароль динамически генерируется внутри функции _createGoodBoy (вызов по адресу 00401357), которая заполняет глобальный буфер с именем _GoodBoy.
2. Изучив декомпилированный код _createGoodBoy, я увидела простой цикл, выполняющийся от i = 0 до 7(всего 8 итераций):
  
  ```C
  for ( i = 0; i <= 7; ++i )
  {
    GoodBoy[i] = _data_start__[i] + 1;
  }
  ```

При проверке ассемблерного кода по адресу .text:00401376 обнаруживается исходная строка, в секции данных по адресу .data:00402000 (__data_start__), со значением "ZCDHAHY\".
3. Расшифровка буфера:
Программа берет каждый символ этой строки и увеличивает его значение ASCII на 1. Если вручную рассчитать результирующие символы:

* 'Z' (90) + 1 = 91 ->[
* 'C' (67) + 1 = 68 ->D
* 'D' (68) + 1 = 69 ->E
* 'H' (72) + 1 = 73 ->I
* 'А' (65) + 1 = 66 ->B
* 'H' (72) + 1 = 73 ->I
* 'Y' (89) + 1 = 90 ->Z
* '\\' (92) + 1 = 93 ->]

4. Результат: Итоговый сгенерированный пароль - [DEIBIZ]. Успешный ввод этого пароля в консоль обходит проверку и выводит: "Well done, have you patched your name?".

## Часть 2: Исправление имени

1. Поиск целевой строки: Заголовок исполняемого файла содержит строку Cracked By: XXXXXXXXXXXX. Для её модификации я перешла в секцию данных .data и по адресу .data:00402009, нашла переменную _CrackedBy, которая хранит эту ASCII-строку с байтами-заполнителями X.
2. Модификация двоичного файла: С помощью функции Edit -> Patch program -> Change byte... в IDA Pro я изменила исходные символы на свое имя - Velana. Поскольку имя было короче 12 символов, я заполнила оставшееся пространство нулевыми байтами ( 00), чтобы не сдвинуть соседние данные и сохранить целостность структуры файла. Затем я применила изменения к исходному файлу через Apply patches to input file....
3. Проверка: После сохранения измененного исполняемого файла и его повторного запуска с правильным паролем [DEIBIZ]в терминале успешно отобразилось следующее: Cracked By: Velana.
